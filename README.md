# AI Student Assistant

AI Student Assistant is a web application that helps students learn more efficiently using Artificial Intelligence.

---

## 🚀 Features

* Explain academic concepts
* Generate multiple choice questions (MCQs)
* Summarize long text
* Improve writing quality

---

## 🛠️ Technologies Used

* Frontend: React
* Backend: Node.js, Express
* API: Google Gemini API
* HTTP Client: Axios

---

## ⚙️ How It Works

1. User enters a prompt
2. Selects a mode (Explain, MCQ, Summarize, Improve)
3. Request is sent to backend
4. Backend processes it using AI
5. Response is displayed in UI

---

## 📂 Project Structure

```
client/   → Frontend (React)
server/   → Backend (Node.js & Express)
```

---

## ▶️ Run the Project

### Backend

```
cd server
npm install
node server.js
```

### Frontend

```
cd client
npm install
npm start
```

---

## 🔑 Environment Variables

Create a `.env` file inside the **server** folder:

```
AI_API_KEY=your_api_key_here
PORT=5000
```
